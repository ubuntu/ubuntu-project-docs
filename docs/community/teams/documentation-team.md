# Documentation team

The Ubuntu Documentation team writes and maintains the core documentation for Ubuntu, including the official documentation sets and the community wiki content.
It is the starting point for anyone interested in improving Ubuntu documentation.

All of the work produced by the Ubuntu Documentation team is released under the terms of the [Creative Commons Attribution-ShareAlike 3.0 license](https://creativecommons.org/licenses/by-sa/3.0/) (CC BY-SA 3.0).

## Meetings

The Documentation team holds a weekly [Open Documentation Hour](https://discourse.ubuntu.com/t/community-hour-ideas-pool/45291) at 16:00 UTC each Friday, hosted by the Open Documentation Academy.
Everyone is welcome.


## Authority

The official Ubuntu documentation sets each have their own maintainers and review processes.
Changes are reviewed through the version control systems that host the documentation sources; see {ref}`how-to-contribute-docs` for how reviews work in the Ubuntu project documentation.


## Contributing

Documentation is a great gateway into open source contributions.
To get started:

* {ref}`how-to-contribute-docs` explains how to contribute to the Ubuntu project documentation
* The [Open Documentation Academy](https://documentation.academy/) offers tasks, structured support, and recognition for new contributors
* You can report mistakes or highlight missing documentation by filing an issue from any documentation page

You can also join the {matrix}`documentation` Matrix room or the ubuntu-doc mailing list and ask where help is most needed.
