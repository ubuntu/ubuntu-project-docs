# Kernel team

The Ubuntu Kernel team aims to provide the highest quality Linux kernel for Ubuntu and the Ubuntu family of products.
The Linux kernel is the core of Ubuntu and is the rock upon which all other Ubuntu technology is based.

Specific areas that the Kernel team is responsible for include, in no particular order:

* Developing in an open model, in collaboration with the community and upstream
* Enabling a wide range of hardware, to match trends and user expectations of Ubuntu's goals
* Maintaining the central Linux kernel packages for Ubuntu's supported architectures and ports
* Development standards and collaborative development support for the Ubuntu Linux kernel
* The Ubuntu kernel {spellexception}`git` tree
* The kernel-team mailing list
* Automated vanilla Linux kernel builds and packaging
* Selecting the Linux kernel version for each Ubuntu release
* Serving as the interface to the Linux kernel upstream
* Ubuntu kernel bug policies
* Community documentation on how to contribute to the Ubuntu kernel
* Ubuntu kernel road maps for new releases
* Ubuntu Kernel team weekly reporting


## Communication

**Matrix**
: {matrix}`kernel`

**Mailing list**
: [kernel-team](https://lists.ubuntu.com/mailman/listinfo/kernel-team) (medium traffic). The list is run much like the Linux Kernel Mailing List ({spellexception}`LKML`): users can propose patches, ask questions and find general information.

**Launchpad**
: [~ubuntu-kernel-team](https://launchpad.net/~ubuntu-kernel-team) is the moderated public team in which the Kernel team interacts with the Ubuntu community. [~canonical-kernel-team](https://launchpad.net/~canonical-kernel-team) is a private team used for Canonical-paid hardware enablement and other Canonical business.

**Documentation**
: The team maintains its technical documentation on [kernel.ubuntu.com](https://kernel.ubuntu.com)


## Meetings

No regular public meeting is currently advertised.
The team provides weekly reports on its work through its usual communication channels.


## Authority

The Kernel team is led by Canonical's Ubuntu Platform Kernel team and selects the kernel version for each Ubuntu release.
Decisions are made in the open on the kernel-team mailing list and in the {matrix}`kernel` Matrix room.


## Contributing

The Kernel team welcomes contributions in the open, in collaboration with the community and upstream.
The kernel documentation on [kernel.ubuntu.com](https://kernel.ubuntu.com) explains how the Ubuntu kernel is built and how to contribute to it.

You can propose patches and ask questions on the [kernel-team mailing list](https://lists.ubuntu.com/mailman/listinfo/kernel-team) or in the {matrix}`kernel` Matrix room.
To report a bug in the Ubuntu kernel, see {ref}`how-to-report-a-bug`.
