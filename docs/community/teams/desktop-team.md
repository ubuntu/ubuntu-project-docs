# Desktop team

The Ubuntu Desktop team handles all the packages that go into the Ubuntu desktop installation.
Its mission is to produce a desktop environment that is stable, usable, accessible, attractive, consistent, discoverable, and immediately useful.

The team's work falls into two areas:

* **Maintenance**: keeping up to date with new upstream releases, triaging and fixing reported bugs, testing the desktop, and deciding which packages should compose it.
* **Development**: improving the user experience, both by improving the usability of the existing desktop and by developing new interface concepts.


## Communication

**Mailing list**
: [ubuntu-desktop](https://lists.ubuntu.com/mailman/listinfo/ubuntu-desktop) (medium traffic)

**IRC**
: `#ubuntu-desktop` on [Libera.Chat](https://libera.chat/)

**Discourse**
: The [Desktop section](https://discourse.ubuntu.com/c/project/desktop/8) of the Ubuntu Discourse hosts discussions, calls for testing, and the team's [weekly reports](https://discourse.ubuntu.com/tags/c/project/desktop/8/team-update)


## Meetings

The team publishes weekly reports on [the Ubuntu Discourse](https://discourse.ubuntu.com/tags/c/project/desktop/8/team-update).
No regular public meeting is currently advertised.


## Authority

The Desktop team decides which packages compose the Ubuntu desktop and maintains the corresponding packages in the Ubuntu archive.
The team is made up of Ubuntu developers with upload rights for the desktop package set.


## Contributing

There are many ways to contribute to the Ubuntu desktop, whatever your skill level:

* Test the desktop and report problems (see {ref}`how-to-report-a-bug`)
* Help triage and fix reported bugs
* Answer calls for testing and discuss ideas on [the Ubuntu Discourse](https://discourse.ubuntu.com/c/project/desktop/8)

If you find yourself doing a lot of desktop work, introduce yourself on the mailing list or the Discourse and ask about getting more involved.
