# Ubuntu Studio team

Ubuntu Studio is an official flavor of Ubuntu, and the most widely used multimedia-orientated {spellexception}`GNU/Linux` distribution in the world.
It provides an installable disk for multimedia production machines, and the team works to better maintain the multimedia applications in Ubuntu.

Ubuntu Studio is a community effort, targeted at all skill levels from beginner to professional.
It aims to be easy to install and easy to use, while providing all the tools necessary for any type of media content creation.

The team's goal is to be an example of how to configure a Debian- and Ubuntu-based operating system for its [workflows](https://ubuntustudio.org/tour/), contributing improvements upstream to Debian, and communicating with developers directly through testing, fixing bugs, and providing feedback.
It also aims to be the gateway for new users coming into the Linux world who want to use Linux for multimedia content creation.


## Communication

: {matrix}`ubuntustudio-devel` is the main hub for Ubuntu Studio development — drop by, introduce yourself, and don't hesitate to ask questions

**Discourse**
: Ubuntu Studio support questions are handled under the [ubuntu-studio tag](https://discourse.ubuntu.com/tag/ubuntu-studio) on the Ubuntu Discourse

**Website**
: [ubuntustudio.org](https://ubuntustudio.org/), including the [support page](https://ubuntustudio.org/support/) for user support channels and the [developer information](https://ubuntustudio.org/wiki/) for development resources


## Meetings

No regular public meeting is currently advertised.
Development coordination happens in the {matrix}`ubuntustudio-devel` Matrix room.


## Authority

Ubuntu Studio is led by its project leader together with its regular, active contributors.
The project is community-run and is not affiliated with Canonical.


## Contributing

Ubuntu Studio is created by volunteers, and you don't need any particular skills to join — just a friendly attitude, time to commit, and a willingness to learn.
The [contribute page](https://ubuntustudio.org/contribute/) describes the main areas:

* **Support**: answer questions from other users on the Ubuntu Discourse and the support channels
* **Testing**: test pre-release versions of the distribution (much of this can be done in a virtual machine)
* **Documentation**: help keep the Ubuntu Studio website and wiki up to date
* **Packaging**: help maintain the packages that make up Ubuntu Studio in the Debian and Ubuntu repositories
* **Tutorials**: create teaching materials, especially workflow tutorials combining the tools available in the distribution
* **Creative work**: share art, music, videos, and other works made with Ubuntu Studio, and contribute to wallpaper contests and other open calls

For most ways of contributing, you will need a [Launchpad](https://help.launchpad.net/YourAccount/NewAccount) account.
