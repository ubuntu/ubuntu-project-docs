# Translation team

Ubuntu is translated by a large community of volunteers who contribute every day to make the operating system more accessible to millions of users in their own language.

Ubuntu can be translated into almost any language.
If you know languages and want to help, come and join the Ubuntu Translators community and make it possible to use Ubuntu in your own language.


## Communication

**Launchpad**
: Translations are coordinated through [Launchpad Translations](https://translations.launchpad.net/), where each language has its own translation team. The [Ubuntu Translators group](https://translations.launchpad.net/+groups/ubuntu-translators) brings the language teams together.


## Meetings

No regular public meeting is currently advertised.
Each language team coordinates its own work through Launchpad.


## Authority

Translation work is organized into per-language translation teams on Launchpad.
Each team reviews and approves translations for its language, following the common Ubuntu translations guidelines.


## Contributing

Whether you are a translator, a user, or a developer, there are many ways to contribute to Ubuntu Translations:

* {ref}`contribute-to-translation` explains how translations work in Ubuntu and how to get started
* [Join a translation team](https://translations.launchpad.net/+groups/ubuntu-translators) for your language on Launchpad
* Start translating Ubuntu through [Launchpad Translations](https://translations.launchpad.net/)
* {ref}`Report translation bugs <filing-a-translation-bug>` when you find problems in existing translations
