# Xubuntu team

Xubuntu is an official flavor of Ubuntu that develops and promotes the {spellexception}`Xfce` desktop on Ubuntu, striving for an elegant and easy-to-use operating system that is also light and accessible.

The Xubuntu team's home is [xubuntu.org](https://xubuntu.org/), which features download links, the team blog, and information about the project.


## Communication

**Mailing list**
: [xubuntu-devel](https://lists.ubuntu.com/mailman/listinfo/xubuntu-devel) for development discussion

**Website**
: [xubuntu.org](https://xubuntu.org/), including [help and support](https://xubuntu.org/help/) for user support channels


## Meetings

No regular public meeting is currently advertised.


## Authority

Xubuntu's development is coordinated by the Xubuntu team; the principles behind the project are described on the [Xubuntu website](https://xubuntu.org/).


## Contributing

The [Get Involved](https://xubuntu.org/contribute/) page on the Xubuntu website describes the ways you can contribute, including testing, documentation, development, and translations.

Support for Xubuntu users can be found on the [help and support](https://xubuntu.org/help/) page.
